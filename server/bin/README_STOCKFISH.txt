Для настоящего Stockfish положите исполняемый файл сюда:

Windows: server/bin/stockfish.exe
Linux/macOS: server/bin/stockfish

Либо задайте полный путь в .env:
STOCKFISH_BIN=C:\\Tools\\stockfish\\stockfish-windows-x64-avx2.exe

Без бинарника НЕМАКС автоматически использует встроенного резервного шахматного бота.
Уровни 3–7 сохраняются в обоих режимах.
