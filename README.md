Документация для запуска и защиты

НЕМАКС — расширенный full-stack мессенджер
React/Vite PWA и четыре специализированных Node.js backend-сервиса. Регистрация выполняется **только по уникальному логину и паролю** — телефон и электронная почта не требуются.
Архитектура

1. Core API (`3001`)** — авторизация, права, чаты, сообщения, PostgreSQL, S3/MinIO, шифрование, Bot API и REST API.
2. Realtime / Worker (`3002`)** — WebSocket, presence, Redis-очереди, WebRTC-сигналинг, повторная доставка, запланированные сообщения, автоудаление и ротация серверных ключей.
3. Code Runner (`3003`)** — изолированное выполнение учебных JavaScript, Python и Java-проектов из НЕМАКС Code Studio.
4. Game Server (`3004`)** — отдельное состояние игровых столов, серверная проверка шахмат/шашек, турниры и кэш-покер на условные фишки.

В production-контур входят PostgreSQL, Redis, MinIO, Coturn, Nginx, Prometheus и Grafana. Без внешних сервисов проект запускается в локальном fallback-режиме с JSON-базой, локальными файлами и памятью.

- логин/пароль, `scrypt`, короткоживущий access-токен, ротация refresh-токена, активные сессии и их отзыв;

## Быстрый локальный запуск

Требования: Node.js 22+ и npm. Для выполнения проектов Code Studio локально также нужны Python 3 и JDK 17+; JavaScript web/Canvas preview работает в браузере.

```bash
npm install
npm run dev
```

Откроются:
- frontend — `http://localhost:5173`;
- Core API — `http://localhost:3001`;
- Realtime — `http://localhost:3002`;
- Code Runner — `http://localhost:3003` (внутренний сервис);
- Game Server — `http://localhost:3004` (API: `/game-api`);
- WebSocket — `ws://localhost:3002/ws`.

Первый системный администратор создаётся автоматически:

логин: admin
пароль: Admin123!ChangeMe

Production через Docker Compose
cp .env.example .env
Обязательно замените все change-* и INTERNAL_SERVICE_SECRET
docker compose up --build -d

Основная точка входа через Nginx: `http://localhost`. Для публичного сервера подключите TLS-сертификат или внешний HTTPS reverse proxy/CDN.

Сервисы:
- PostgreSQL — постоянное состояние;
- Redis — presence, rate limit, offline queue и служебные потоки;
- MinIO — зашифрованные вложения;
- Coturn — TURN для WebRTC;
- Prometheus — `http://localhost:9090`;
- Grafana — `http://localhost:3000`;
- MinIO Console — `http://localhost:9001`.

Подробности: [`PRODUCTION.md`](./PRODUCTION.md).

Проверка

Данные и ключи
В локальном режиме:
server/data/db.json
server/data/message-keys.json
server/uploads/

Файл `message-keys.json` необходимо резервировать вместе с базой. Потеря этого файла делает серверно-зашифрованную историю невосстановимой.

Честные ограничения

Это очень расширенная готовая основа, но не буквальная копия инфраструктуры Telegram:
- клиентский E2E-режим не является прошедшей аудит реализацией Signal Double Ratchet/MLS;
- групповые звонки работают как WebRTC-сигналинг/P2P-заготовка, без отдельного SFU-кластера;
- PostgreSQL-драйвер сохраняет согласованное состояние транзакционно, но для сотен миллионов пользователей схему нужно нормализовать, партиционировать и шардировать;
- в архив входит PWA и готовая Capacitor-конфигурация для Android; для выпуска APK/AAB всё равно нужны Android Studio, SDK и подпись приложения;
- антивирусная и медиатранскодирующая инфраструктура описана точками расширения, но ClamAV/FFmpeg-воркеры не включены в основной compose.

## Web/PWA и Android

Desktop web-интерфейс оптимизирован для широких экранов, а список чатов можно свернуть до панели аватаров. На мобильных устройствах используются `100dvh`, safe-area и touch-friendly элементы.

Для Android включена Capacitor-обёртка:

npm install
npm run build
npm run android:add
npm run android:sync
npm run android:open
```

Перед сборкой задайте `VITE_API_URL`, `VITE_GAME_API_URL`, `VITE_WS_URL` и `VITE_MEDIA_URL` в `.env.production`. 

Города, чат-комнаты и НЕМАКС PLAY
В интерфейс встроен общий компонент выбора города с локальным справочником `public/data/world-cities.json`. Он используется при регистрации, редактировании профиля, создании/фильтрации досок и создании/поиске чат-комнат. Пользователь выбирает найденный город, регион и страну, а не сохраняет произвольную строку.

Новый раздел `/rooms` поддерживает:
- текстовые, голосовые и игровые комнаты;
- город и произвольные теги интересов;
- публичный вход или заявки;
- лимит участников;
- привязку мини-игры;
- открытие комнаты как обычного чата.

Раздел `/games` содержит:
- викторины, кликеры и тесты реакции;
- визуальный конструктор игр-новелл;
- тетрис и змейку;
- онлайн-шахматы и шашки;
- турниры и кэш-столы Texas Hold’em только на условные фишки;
- Code Studio для JavaScript, Python и Java.

Авторскую игру или новеллу можно сохранить, протестировать, опубликовать, привязать к комнате и вывести в таблицу лидеров. Подробности: [`NOVELS_ARCADE_ONLINE_GAMES.md`](./NOVELS_ARCADE_ONLINE_GAMES.md).

Все выпадающие меню основных пользовательских экранов заменены на тематический `CustomSelect`, а нативные select получили единый резервный стиль. Фильтры объявлений больше не выглядят как простые овальные чипы: используются компактные карточки с иконкой, названием, пояснением и активным состоянием.

ИИ-собеседники и «Избранное»

Для каждого обычного пользователя автоматически создаются личный self-chat **«Избранное»** и пять явно обозначенных ИИ-аккаунтов: Лея, Мира, Ника, Макс и Артём. Генерация вынесена в отдельный AI Server на порту `3005`; устойчивые системные промпты хранятся только на backend. Без внешнего ключа доступен демонстрационный режим, а полноценные ответы подключаются через Ollama или OpenAI-compatible API. Подробности: `AI_COMPANIONS_AND_SAVED.md`.

Единый аудио- и видеоплеер
НЕМАКС использует собственные адаптивные плееры вместо стандартных браузерных controls. Аудио продолжает играть между страницами через глобальный мини-плеер. Видео поддерживает перемотку, громкость, скорость, полноэкранный режим, Picture-in-Picture и продолжение с сохранённой позиции. Подробности: `MEDIA_PLAYER.md`.

Windows hotfix: база, AI, Code Studio, медиа и шахматный бот
Подробности находятся в `HOTFIX_WINDOWS_AI_STOCKFISH_MEDIA.md`.

Проверка исправлений:

```powershell
npm run test:hotfix
npm run test:code-runner
npm run test:ai-provider
```

Настоящий Stockfish подключается через `STOCKFISH_BIN` или файл `server/bin/stockfish.exe`. Без бинарника шахматный режим использует встроенный резервный minimax-движок и показывает это в интерфейсе.
