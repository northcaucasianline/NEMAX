# Отчёт проверки НЕМАКС

Дата проверки: 2 августа 2026 года.

## Статические проверки

Успешно выполнено:

- `node --check` для всех 24 JavaScript-файлов backend и служебных скриптов;

- проверка относительных импортов frontend;

## Проверка Code Runner

Команда:

```bash
npm run test:code-runner
```

Результаты:

- JavaScript: `2 + 3 = 5`;
- Python: `6 * 7 = 42`;
- Java: `9 * 9 = 81`;
- компиляция Java и запуск JVM завершились успешно;
- stdout, stderr, exit code, timeout и длительность возвращаются Core API.

Отдельно проверен Unix socket transport, используемый Docker Compose:

- Runner создал сокет с режимом `0660`;
- JavaScript, Python и Java были выполнены через socket;
- дочерний код запускался под UID/GID `10002`;
- попытка дочернего JavaScript-процесса прочитать окружение родительского runner была отклонена runtime/OS.

## Ограничение среды проверки

Полный `npm install` и `vite build` выполнить не удалось: внутренний npm-registry среды вернул `404` для `@aws-sdk/client-s3`. Это ограничение среды загрузки зависимостей, а не выявленная ошибка исходного кода.

Docker CLI также отсутствует, поэтому контейнеры не собирались фактически. Docker Compose и Dockerfile проверены статически, а Unix socket, смена UID и выполнение всех трёх языков проверены непосредственно в Linux-среде.
