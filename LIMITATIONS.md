# Ограничения текущего архива

Реализована широкая функциональная основа, однако следующие задачи требуют отдельных крупных систем:

1. **Telegram-scale storage.** Текущий PostgreSQL adapter хранит цельное согласованное состояние в JSONB. Для высокой нагрузки нужны нормализованные таблицы, partitioning, read replicas и шардирование.
2. **Аудированное E2E.** Есть server-blind ECDH/AES-GCM режим, но нет завершённого Signal Double Ratchet/MLS, key transparency и независимого аудита.
3. **Групповые видеоконференции.** Есть WebRTC и TURN, но нет SFU/MCU вроде mediasoup/Janus/LiveKit.
4. **Монетизация.** Платёжные, Premium, рекламные и платные контентные логики намеренно удалены. Все функции доступны одинаково для всех пользователей.
5. **Нативные клиенты.** Поставляется PWA и Capacitor-конфигурация Android. Подписанный APK/AAB и отдельные iOS/Desktop-клиенты не входят в архив: Android-проект генерируется командой `npm run android:add` на машине с Android SDK.
6. **Media pipeline.** Файлы шифруются и сохраняются, но автоматическое FFmpeg-транскодирование, OCR и ClamAV требуют отдельных worker-контейнеров.
7. **Массовая модерация.** Есть роли, жалобы и ограничения, но ML-антиспам, abuse-центр и юридические процессы должны строиться отдельно.

Эти ограничения не мешают локальному запуску, демонстрации, закрытой бете и дальнейшей разработке, но важны перед публичным массовым запуском.


## Code Studio

Это учебная мини-IDE, а не полный аналог VS Code/IntelliJ. Нет LSP, debugger, Maven/Gradle, pip/npm install и desktop GUI. Python и Java ориентированы на консольные приложения. Локальный process-runner следует использовать только на доверенном компьютере; для общего доступа обязателен изолированный Docker runner. Для массового запуска полностью недоверенного кода всё равно рекомендуются отдельные worker-хосты или одноразовые microVM.

## ИИ-собеседники

- В архив не включены веса языковой модели и платный API-ключ. Режим `demo` проверяет интеграцию, но не заменяет полноценную нейросеть.
- Качество, актуальность и скорость ответа зависят от подключённой через Ollama или OpenAI-compatible API модели.
- ИИ-чаты не являются E2E: Core API должен получить открытый текст, чтобы передать ограниченный контекст AI Server.
- Реализована ограниченная история диалога, но не векторная долговременная память и не обучение модели на пользователе.
- ИИ может ошибаться; интерфейс явно предупреждает об этом и помечает все созданные ответы.
