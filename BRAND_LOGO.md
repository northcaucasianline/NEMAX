# Логотип НЕМАКС

В проект внедрён пользовательский логотип на основе файла `a2dcb3fa-098c-502f-a797-8b296559fbd0.png`.

Использование:

- `public/nemax-logo.png` — основная бренд-картинка.
- `public/nemax-logo-mark.png` — квадратный логотип для интерфейса.
- `public/nemax-icon-192.png` — PWA-иконка.
- `public/nemax-icon-512.png` — PWA-иконка большого размера.

Где применяется:

- шапка приложения;
- экран входа;
- экран регистрации;
- favicon браузера;
- PWA manifest;
- push-уведомления через service worker.
