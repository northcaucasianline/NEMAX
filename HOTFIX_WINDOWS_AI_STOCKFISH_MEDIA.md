# Исправления Windows, AI, Code Studio, медиа и шахмат

## 1. Ошибка `EPERM rename db.json.tmp -> db.json`

На Windows антивирус, индексатор или другой процесс иногда кратковременно удерживает JSON-файл. Теперь запись выполняется через уникальный временный файл, несколько повторов и безопасный прямой fallback. Ошибка одной операции больше не блокирует последующие сохранения.

## 2. Шахматы с компьютером

В форме создания шахматного стола появился выбор:

- против человека;
- против Stockfish;
- уровень 3–7.

Для настоящего Stockfish укажите в `.env`:

```env
STOCKFISH_BIN=C:\Tools\stockfish\stockfish-windows-x86-64-avx2.exe
```

Или положите `stockfish.exe` в `server/bin`. Если бинарник не найден, используется встроенный резервный minimax-бот, а интерфейс показывает это явно.

## 3. Квадратная доска

Шахматная доска теперь имеет `aspect-ratio: 1`, ровно 8 колонок и 8 строк. У клеток сброшены внешние отступы, padding и минимальные размеры, поэтому все 64 поля одинаковы.

## 4. AI и Polza.ai

Пример `.env`:

```env
AI_PROVIDER=polza
AI_API_BASE_URL=https://polza.ai/api/v1
AI_MODEL=deepseek/deepseek-v3
AI_API_KEY=pza_ваш_ключ
```

Проверка:

```powershell
npm run test:ai-provider
```

AI Server теперь выводит реальную безопасную причину ошибки: HTTP-код, неверную модель, отсутствие ключа или таймаут. Ключ в сообщениях скрывается.

## 5. Python и Java на Windows

Code Runner автоматически ищет:

- `py -3`;
- `python`;
- `python3`;
- `java` и `javac`;
- `JAVA_HOME`;
- явные `PYTHON_BIN`, `JAVA_BIN`, `JAVAC_BIN`.

Проверка:

```powershell
npm run test:code-runner
curl.exe http://127.0.0.1:3003/health
```

Если Python/JDK не установлены, интерфейс теперь показывает понятную инструкцию вместо кода 9009.

## 6. Голосовые и видео

Перед записью браузер выбирает реально поддерживаемый MIME-кодек. Сервер сохраняет фактический MIME и корректное расширение. Для новых записей поддерживаются WebM/Opus, Ogg/Opus и MP4 там, где это позволяет браузер.

Старые файлы, записанные до исправления с неверным MIME или уже повреждённые, автоматически восстановить невозможно — их нужно записать заново.

## 7. ИИ-профили

Пять ИИ-персонажей получили разные человекоподобные портреты и индивидуальные естественные приветствия. Они по-прежнему явно помечены как ИИ.
